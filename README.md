# 애니 캐릭터 이상형 월드컵

참여자는 **로그인 없이** 링크만 열면 됩니다. 휴대폰에 맞춰 만들었습니다.

- **캐릭터 등록**: 사진을 고르고 이름을 적어 올립니다(최대 140명).
  - 사진은 **원본 화질**로 저장합니다. 700KB 이하는 손대지 않고 그대로, 더 큰 사진은 긴 변 최대 2048px 고품질로 저장합니다. Firestore 문서 한도가 1MB이기 때문입니다.
  - 목록·순위 화면은 작은 썸네일만 불러와 가볍게 유지합니다. 대결 화면에서만 그 판의 고화질 두 장을 불러오고, 다음 판 사진은 미리 받아 둡니다.
- **월드컵**: 8·16·32·64·128강 또는 전체 중에서 고릅니다. 무승부면 둘 다 진출하고, 결승 무승부는 공동 우승입니다.
- **결과**: 나의 TOP 10과 모두의 TOP 10(참여자 점수 합산)을 보여줍니다.

Firebase를 설정하기 전에는 **체험 모드**로 동작합니다. 이때는 이 브라우저에만 저장되고 다른 사람과 공유되지 않습니다.

### 테스트 도구 (체험 모드 전용)
**캐릭터 등록** 탭 맨 아래 🧪 테스트 도구 버튼으로 할 수 있는 것:
- **가짜 캐릭터 140명 채우기**: 서로 다른 애니풍 그림과 이름이 자동으로 만들어집니다.
- **가짜 참여자 30명 결과 만들기**: 30명이 월드컵을 끝낸 것처럼 결과를 쌓아서 "모두의 TOP 10"을 확인합니다. 누를 때마다 30명씩 늘어납니다.
- **테스트 데이터 모두 지우기**

Firebase를 연결하면 이 버튼들은 보이지 않습니다. 대신 주소 끝에 `?demo`를 붙이면(예: `.../anime-worldcup/?demo`) 실제 데이터와 무관한 체험 모드로 열립니다.

## 1단계: Firebase 만들기 (무료, 약 10분)

1. <https://console.firebase.google.com> 에서 **프로젝트 추가**를 누릅니다. 이름은 자유이고, Google 애널리틱스는 꺼도 됩니다.
2. 프로젝트 홈에서 **웹 앱 추가**(`</>` 아이콘)를 누르고 앱 이름을 적습니다. Hosting 체크는 필요 없습니다.
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값 6개를 [firebase-config.js](firebase-config.js)에 그대로 붙여넣습니다.
   - apiKey가 공개돼도 괜찮습니다. 웹용 Firebase 키는 원래 공개하는 값이고, 실제 보호는 아래 보안 규칙이 맡습니다.
4. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법**에서 **익명**을 **사용 설정**합니다.
   - 참여자에게는 아무 화면도 뜨지 않습니다. "이 기기에서 올린 사진만 내가 지울 수 있게" 하는 용도입니다.
5. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작합니다.
6. Firestore의 **규칙** 탭에서 기존 내용을 지우고 [firestore.rules](firestore.rules) 내용을 붙여넣은 뒤 **게시**합니다.

> 사진은 Firestore에 직접 저장합니다. 목록용 썸네일은 `characters`, 고화질은 `images` 컬렉션에 들어갑니다(1장에 최대 약 1MB). Firebase Storage는 이제 유료 요금제 등록이 필요해서 쓰지 않았습니다. 무료 한도(저장 1GB, 하루 읽기 5만 건)면 140명과 참여자 수십~수백 명까지 충분합니다.

## 2단계: GitHub Pages로 배포

1. <https://github.com/new> 에서 새 저장소를 만듭니다(예: `anime-worldcup`). **Public**으로 만듭니다.
2. **uploading an existing file**을 누르고 이 `web` 폴더 안의 파일을 전부 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - `index.html`, `app.js`, `store.js`, `style.css`, `firebase-config.js` (`README.md`, `firestore.rules`는 넣어도 되고 안 넣어도 됩니다)
3. 저장소의 **Settings → Pages → Branch: `main` / `(root)` → Save**를 누릅니다.
4. 1~2분 뒤 `https://<내아이디>.github.io/anime-worldcup/` 주소가 생깁니다. 이 링크를 참여자에게 보내면 됩니다.

## 관리

- 남이 올린 캐릭터나 이상한 사진은 Firebase 콘솔의 **Firestore → characters**에서 해당 문서를 삭제합니다. **images**에서 같은 ID의 문서(고화질 사진)도 함께 지우세요.
- 순위를 초기화하려면 **results** 컬렉션을 삭제합니다.
- 월드컵 진행 중 상태는 각 참여자의 휴대폰에 저장됩니다. 창을 닫아도 **이어하기**가 됩니다.

## 순위 계산

- **나의 TOP 10**: 늦게 탈락한 순서로 줄 세웁니다. 같은 라운드에서 탈락했다면 승 → 무 → 패 순으로 비교합니다.
- **모두의 TOP 10**: 각 참여자의 TOP 10에 1위 10점부터 10위 1점까지 주고 합산합니다. 동점이면 우승 횟수, 그다음 승률(무승부 = 0.5승) 순입니다.
